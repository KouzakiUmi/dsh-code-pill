# 设置指南

[返回首页](../README.md) · [兼容性与权限](compatibility.md)

> 本文对应 0.5.0 实现；实际发布状态以 npm 与 GitHub Release 为准，不将 main 推送等同于发布。变更见 [更新记录](../CHANGELOG.md)。

## 打开设置

在支持设置扩展的 DSH 宿主中，进入 **设置 → Code Pill**。
页面分为「代码外观」和「字体」两个 Tab。代码外观包含预设、色板与预览、显示与排版、配置管理四组；切换 Tab 不丢失外观草稿。字体即时应用，不需要点击外观 Tab 的保存按钮。
找不到入口时先核对安装包是不是当前 main 构建，以及宿主是否提供设置 slot 和 UI 模块；没有设置入口不意味着行内渲染也一定失败。

## 先选预设

| 预设 | ID | 基调 |
| --- | --- | --- |
| 琥珀经典 | `amber` | 延续默认琥珀色 |
| 柔和阅读 | `readable` | 中性石板色 |
| 冷调清晰 | `cool` | 青蓝色 |
| 编辑器经典 | `editor` | 熟悉的编辑器语法色 |
| 高对比 | `contrast` | 更强的明暗对比 |
| 素雅简约 | `minimal` | 中性灰默认文字与克制的语法色 |

每套分别提供 light/dark 色板。**选择预设会替换整份外观草稿，包括排版和开关参数**；已经手调的内容不会被自动合并。保存之前仍可通过“取消更改”返回已保存配置。

「素雅简约」(minimal) 同时替换几何默认值：圆角 3px、水平内边距 0.2em、底色强度 0.025（其余预设为 4px、0.25em、0.06）；语法着色保持开启、文件标记保持语言文字、字号比例保持 0.94×，不隐藏任何功能。

色板名称不代表护眼、医疗或所有环境的可读性保证。实际背景、字号与个人视觉需求仍应一起考虑。

## 自定义颜色

“浅色／深色”按钮选择正在编辑与预览的色板，不强制切换真实聊天主题。运行时颜色跟随宿主主题。

| 角色 | 用途 |
| --- | --- |
| 默认文字 | 标识符、路径、文件名及未独立着色的部分 |
| 控制流 | if、return 等关键词 |
| 声明与类型 | const、class 等声明关键词 |
| 字符串 | 带引号的字符串 |
| 注释 | 启发式识别出的代码注释 |
| 数字 | 数字字面量 |
| 胶囊底色 | 与底色强度一起合成背景 |
| 徽章底色／文字 | 文件语言标签的实色背景与文字 |

颜色选择器立即更新草稿。十六进制输入需完整 `#RRGGBB`，失焦时校验；不合法时恢复原值并提示。
函数调用、类型名、常量与属性默认并入默认文字色，并非九种独立语法色。

预览使用白色／`#1e1e1e` 背景，并显示当前颜色的文字对比度结果。低于 4.5:1 会提醒，**仍允许保存，不会自动替你改颜色**。这是当前预览条件下的检查，不是任意宿主主题的全面审计。

## 文件标记与排版

| 选项 | 默认 | 可选范围 |
| --- | --- | --- |
| 行内语法着色 | 开启 | 开启／关闭；关闭仍保留胶囊与文件标记 |
| 聊天文件路径 | 开启 | 开启／关闭；关闭后聊天中的宿主路径装饰全部撤销 |
| 文件标记 | 语言文字 | 关闭／语言文字／小图标／图标＋文字 |
| 字号比例 | 0.94× | 0.8–1.1×，相对正文 |
| 圆角 | 4px | 0–10px |
| 水平内边距 | 0.25em | 0–0.6em |
| 底色强度 | 0.06 | 0–0.2 |
| 代码块颜色 | 保留宿主 | 保留宿主／使用当前色板 |

文件标记只作用于检测出的文件名。图标＋文字模式在文件名前放单色图标、文件名后放语言缩写；普通表达式不加文件图标。
含空白的路径或不明确的字符串可能不显示标记，这是保守识别，不是文件访问失败。

“聊天文件路径”统一工具摘要、正文文件引用、搜索结果文件名、读取卡片标题及聊天内路径标签的胶囊外观。保留点击、行号跳转和宿主截断结构；读取标题不重复语言标签，已有宿主图标的引用不叠加图标。明确的路径容器可显示含空格、未知扩展名和长路径，但不保证都有语言徽章。URL、命令描述、匹配正文、行号、文件大小与附件卡片不受影响。配置键沿用 `toolPath`。路径保持单色，终端与 diff 仍由宿主负责。

“使用当前色板”生成 Shiki CSS 变量，不提供新的语言解析器。代码块预览只是示意，真实宿主完整渲染应现场核验。

## 草稿、保存与恢复

1. 改动先进入草稿，预览更新，聊天不变。
2. **保存并应用**：写入本浏览器设置并更新聊天。
3. **取消更改**：恢复最近的已保存配置。
4. **恢复默认**：默认配置进入草稿，仍需保存才应用。
5. 关闭设置页：丢弃尚未保存的草稿。

保存失败时保留草稿并显示错误，不应用到聊天。浏览器隐私策略、网站存储禁用或存储配额可能造成失败。

## 导入与导出

展开“导入／导出配置”。

- **导出草稿**：把当前配置 JSON 放入文本框，选中复制；不导出聊天记录或凭据。
- **导入草稿**：粘贴 JSON 后点击导入，校验成功才进入草稿；仍需保存才应用。
- 配置格式要求 `version: 1`，只接受已知字段、合法枚举、范围内数值与六位十六进制颜色。
- 不接受 CSS、脚本、远程字体或图标地址；非法导入不会替换已保存设置。

完整数据契约与验证函数见 [settings-core.cjs](../src/settings-core.cjs)。不要向外观配置填入密钥或其他敏感信息。

## 字体 Tab

- **全局字体 / 等宽字体**：输入逗号分隔的字体栈，留空跟随宿主。没有固定字体候选或组合按钮，不假定客户端已安装任何字体；已有字体配置保持不变。
- **读取 / 刷新本机字体**：用户主动点击后请求 Local Font Access 权限。候选只来自浏览器本次提供的字体（不保证系统全量），字体文件的 cmap、maxp、hhea、hmtx 数据表仅在本页解析，不上传、不下载、不分发。名单只保留在当前插件会话内，不新增永久保存，也不使用旧名单缓存；可用「清除已读取名单」撤销本次候选，不影响已选字体配置。浏览器撤权不会自动清空历史会话名单，可主动清除或刷新；历史旧缓存不自动删除。
- **分类与搜索**：支持全部、英文 / 拉丁字母、中文 / 汉字样本、ASCII 等宽、未完整识别，并可按名称搜索。分类依据字符映射与字宽，不依据字体名。英文检查大小写字母和数字；中文检查固定常用简繁汉字样本，不代表覆盖全部中文或某国语言字形；等宽检查全部 95 个可打印 ASCII（含空格、标点），不保证汉字双宽、可变字体实例或浏览器实际排版网格。
- **识别边界**：同一字体可命中多个筛选条件。每个族的所有已枚举字面均满足才确认；字面能力不同、文件读取失败或不支持的格式归入未完整识别，仍可在全部 / 未完整识别中选择。拒绝、策略限制或 API 不支持时可继续手动输入；刷新失败会清空过时候选，不清空已选字体栈。
- **界面缩放**：100 / 110 / 120 / 130 / 140%，放大整个页面布局；与浏览器缩放并非完全相同，弹窗和布局需按实际宿主核验。
- **会话字号**：10–22px，留空使用宿主设置。
- **高级**：35 个角色、字号和 Markdown 槽位，高级覆盖优先于全局；另可添加选择器 → 字体规则。未知变量与无效选择器不会生成覆盖 CSS。
- **导出 / 固化**：查看及复制当前字体 CSS；代码外观 JSON 导入导出不包含字体配置。

字体改动即时应用并独立保存到 `dsh-code-pill.fonts.v1`；存储失败时本页仍生效，但明确提示未持久化。首次没有新配置时读取 `dsh-font-lab/v1`，不删除或改写原配置。旧插件仍开启会产生样式竞争，建议启用合并版本前自行停用旧插件。

总开关关闭会撤销字体、字号与缩放覆盖；「清除字体、字号与缩放设置」清空字体、字号、缩放和高级配置，不改动代码外观。旧 `dsh-font-lab/fonts` 名单不再读取或改写。切换 Tab 会取消未完成的读取，迟到结果不会写回；高级面板只在展开时挂载字体选择器。

## 保存在哪里

配置 key 为 `dsh-code-pill.settings.v1`，存放在当前浏览器、当前 origin 的 localStorage。

- 不保存到主机 Profile，不自动跨设备同步。
- 协议、主机或端口变化后是另一份存储，例如两个不同端口的 DSH 页面。
- 清除网站数据会删除配置。
- 同 origin 的其他页面可在保存后接收更新；正在编辑的草稿不被强行覆盖。
- 同 origin 的其他脚本可能读取 localStorage，不能把它当作加密秘密库。

## 常见问题

**找不到设置页？** 使用当前 main 的验证包，并检查宿主能力。npm 已发布版本可能还没有新增设置。缺少 UI 模块时不会加载额外 React 副本作为补丁。

**改了颜色，聊天没有变化？** 先点击保存。预览主题切换只选择编辑哪套色板；真实聊天仍跟随宿主主题。

**某些代码没有分色？** 路径、术语和普通标识符默认 plain；不明确的语法保守处理。缺少 Highlight API 或 code 不是单 Text 节点时也会降级。

**文件链接没有胶囊或图标？** 插件主动避开链接、按钮与代码块，避免破坏宿主自己的交互和渲染。

**另一台设备没有同步？** 当前没有云同步。通过导出／导入转移配置即可。
